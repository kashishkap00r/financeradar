# Subtext Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Subtext tab to FinanceRadar showing everything five named writers authored in the last 14 days, in one chronological river, filterable per person.

**Architecture:** A `people.json` config declares each person and their channels. `subtext_fetcher.py` resolves each channel to a feed URL, delegates fetching to the existing `feeds.fetch_feed()` (inheriting proxy/curl/TLS fallbacks), then admits items through a two-tier attribution gate — `owned` channels are trusted structurally, `discovered` channels pass a scored authored-vs-about filter. `aggregator.py` calls it once per hourly run with cache fallback, mirroring `companies_fetcher`.

**Tech Stack:** Python 3.8+ stdlib only (`urllib`, `json`, `re`, `datetime`), `unittest`, vanilla JS, CSS. Spec: `docs/superpowers/specs/2026-07-29-subtext-design.md`.

## Global Constraints

- **Python 3.8+**, 4-space indent, `snake_case` functions, `UPPER_CASE` constants.
- **No new dependencies.** `requirements.txt` contains only `telethon>=1.36`. Use stdlib only.
- **Never edit `index.html` directly.** Edit `templates/app.js` / `templates/style.css`, then run `python3 aggregator.py` to regenerate.
- **Escape literal braces as `{{` / `}}`** in any HTML/CSS/JS written inside `aggregator.py` f-strings. Files under `templates/` use normal braces.
- **Light-only theme.** Do not add dark-mode variables, toggles, or `prefers-color-scheme` blocks.
- **Rolling 14-day window. Authored-only.** No backfill, no accumulation store, no content merely *about* a person.
- **All tests are `unittest`** in `tests/test_*.py`, run via `python3 -m unittest discover -s tests`. Baseline is 168 passing tests — keep them green.
- **Escape all user/feed data in the frontend** with `escapeHtml`, `escapeForAttr`, `sanitizeUrl`. Feed content is untrusted.
- **Subtext category dot colour is `#8C4F5B`**, keyboard shortcut `8`.
- Work on branch `feature/subtext`. Note the hourly RSSHub timer may add cache commits to this branch; that is expected and harmless.

"""
Subtext: person-centric aggregation.

Follows a curated list of writers and surfaces everything they *authored* in a
rolling window, regardless of where it was published. Configuration lives in
people.json so adding a person needs no code change.

Two-tier attribution:
  - "owned" channels (a personal X account, an author-scoped blog feed) cannot
    structurally contain someone else's writing, so they are trusted as-is.
  - "discovered" channels (Google News site queries) are scored by
    is_authored_by() to separate work *by* a person from coverage *about* them.

Mirrors the live-fetch-with-cache-fallback contract of companies_fetcher.py: a
successful run refreshes static/subtext_cache.json; on failure the caller loads
the cache so a CI hiccup never blanks the tab.
"""

import json
import os
import re
import urllib.parse
from datetime import datetime, timedelta

from articles import IST_TZ, get_sort_timestamp
from config import (
    SUBTEXT_ABOUT_PATTERNS,
    SUBTEXT_ACCEPT_SCORE,
    SUBTEXT_ATTRIBUTION_VERBS,
    SUBTEXT_FRESHNESS_DAYS,
    SUBTEXT_INTERVIEW_PATTERNS,
    SUBTEXT_MAX_PER_PERSON,
    SUBTEXT_OPINION_PATHS,
    SUBTEXT_REJECTED_SAMPLE,
    SUBTEXT_SOURCE_LABELS,
    SUBTEXT_UNSCOPED_LABEL,
)

SCRIPT_DIR = os.path.dirname(os.path.abspath(__file__))
PEOPLE_FILE = os.path.join(SCRIPT_DIR, "people.json")

GOOGLE_NEWS_SEARCH = "https://news.google.com/rss/search?q={q}&hl=en-IN&gl=IN&ceid=IN:en"

VALID_KINDS = ("owned", "discovered")
VALID_TYPES = ("x", "rss", "google", "blogger", "internal")


def load_people(path=None):
    """Load and validate people.json. Returns [] on any failure — never raises."""
    path = path or PEOPLE_FILE
    try:
        with open(path, "r", encoding="utf-8") as f:
            payload = json.load(f)
    except (FileNotFoundError, json.JSONDecodeError, OSError) as err:
        print(f"  [WARN] Subtext: could not load {path}: {str(err)[:80]}")
        return []

    raw = payload.get("people", []) if isinstance(payload, dict) else payload
    if not isinstance(raw, list):
        print(f"  [WARN] Subtext: {path} has no people list")
        return []

    people = []
    for entry in raw:
        if not isinstance(entry, dict):
            continue
        pid = str(entry.get("id") or "").strip()
        name = str(entry.get("name") or "").strip()
        channels = entry.get("channels")
        if not pid or not name or not isinstance(channels, list) or not channels:
            print(f"  [WARN] Subtext: skipping malformed person '{pid or '?'}'")
            continue

        aliases = [
            a.strip() for a in (entry.get("aliases") or [])
            if isinstance(a, str) and a.strip()
        ]
        if name not in aliases:
            aliases.insert(0, name)

        valid_channels = [
            c for c in channels
            if isinstance(c, dict)
            and c.get("kind") in VALID_KINDS
            and c.get("type") in VALID_TYPES
        ]
        if not valid_channels:
            print(f"  [WARN] Subtext: '{pid}' has no valid channels; skipped")
            continue

        people.append({
            "id": pid,
            "name": name,
            "beat": str(entry.get("beat") or "").strip(),
            "aliases": aliases,
            "signature_phrases": [
                p for p in (entry.get("signature_phrases") or []) if isinstance(p, str)
            ],
            "author_slugs": [
                s.lower() for s in (entry.get("author_slugs") or []) if isinstance(s, str)
            ],
            "channels": valid_channels,
        })
    return people
```

def build_channel_feed_config(person, channel, index=0):
    """Resolve a channel declaration into a feeds.fetch_feed() config dict.

    Returns None for `internal` channels (handled by scan_internal_pools) and
    for any channel missing the key its type requires.
    """
    ctype = channel.get("type")
    if ctype == "internal":
        return None

    if ctype == "x":
        handle = str(channel.get("handle") or "").strip()
        if not handle:
            return None
        url = GOOGLE_NEWS_SEARCH.format(
            q=urllib.parse.quote_plus(f"site:x.com/{handle}/status")
        )
        label = "X"

    elif ctype == "rss":
        url = str(channel.get("url") or "").strip()
        if not url:
            return None
        label = str(channel.get("label") or person["name"]).strip()

    elif ctype == "blogger":
        host = str(channel.get("host") or "").strip()
        blog_label = str(channel.get("label") or "").strip()
        if not host or not blog_label:
            return None
        url = (
            f"https://{host}/feeds/posts/default/-/"
            f"{urllib.parse.quote(blog_label)}?alt=rss"
        )
        label = host

    elif ctype == "google":
        terms = f'"{person["name"]}"'
        site = channel.get("site")
        if site:
            terms = f"site:{site} {terms}"
        extra = str(channel.get("query_extra") or "").strip()
        if extra:
            terms = f"{terms} {extra}"
        url = GOOGLE_NEWS_SEARCH.format(q=urllib.parse.quote_plus(terms))
        label = SUBTEXT_SOURCE_LABELS.get(site, site) if site else SUBTEXT_UNSCOPED_LABEL

    else:
        return None

    # An explicit per-channel label always wins over the derived one.
    label = str(channel.get("label") or label).strip()

    return {
        "id": f"subtext-{person['id']}-{index}-{ctype}",
        "name": label,
        "url": url,
        "feed": url,
        "category": "Subtext",
        "publisher": person["name"],
    }
```

def _article_text(article):
    """Lowercased title + description, for term matching."""
    return f"{article.get('title', '')} {article.get('description', '')}".lower()


def _alias_in_title(person, article):
    title = (article.get("title") or "").lower()
    return any(alias.lower() in title for alias in person.get("aliases", []))


def score_article(person, article):
    """Score how likely it is that `person` WROTE this article.

    The pivotal signal is inverted from intuition: because the candidate reached
    us via a query on the person's name, the name already appears somewhere on
    the page. If it appears in the TITLE the piece is probably *about* them; if
    it does not, the match was almost certainly the byline.
    """
    title = (article.get("title") or "").lower()
    text = _article_text(article)
    link = (article.get("link") or "").lower()
    score = 0

    if any(p.lower() in text for p in person.get("signature_phrases", [])):
        score += 3
    if any(slug in link for slug in person.get("author_slugs", [])):
        score += 3
    if any(path in link for path in SUBTEXT_OPINION_PATHS):
        score += 2

    if _alias_in_title(person, article):
        score -= 2
        if any(verb in title for verb in SUBTEXT_ATTRIBUTION_VERBS):
            score -= 3
    else:
        score += 1

    if any(p in title for p in SUBTEXT_INTERVIEW_PATTERNS):
        score -= 3
    if any(p in title for p in SUBTEXT_ABOUT_PATTERNS):
        score -= 4

    return score


def is_authored_by(person, article, channel):
    """Decide whether to admit an article. Returns (admitted, score).

    Owned channels are trusted structurally (score 99). Discovered channels pass
    declarative hard gates first (score -99 on rejection), then scoring.
    """
    if channel.get("kind") == "owned":
        return True, 99

    link = (article.get("link") or "").lower()
    require_path = channel.get("require_path") or []
    if require_path and not any(str(p).lower() in link for p in require_path):
        return False, -99

    require_terms = channel.get("require_terms") or []
    if require_terms:
        text = _article_text(article)
        if not any(str(t).lower() in text for t in require_terms):
            return False, -99

    score = score_article(person, article)
    return score >= SUBTEXT_ACCEPT_SCORE, score
```

# Pools scanned by `internal` channels. "twitter" is excluded on purpose: `x`
# channels already claim it by handle, which is a stronger signal than a name match.
INTERNAL_POOL_NAMES = ("news", "reports", "papers")


def tag_article(person, article, channel):
    """Return a copy of `article` stamped with person + channel provenance."""
    tagged = dict(article)
    tagged["person_id"] = person["id"]
    tagged["person_name"] = person["name"]
    tagged["channel_kind"] = channel.get("kind", "discovered")
    tagged["channel_type"] = channel.get("type", "")
    tagged["category"] = "Subtext"
    return tagged


def scan_internal_pools(person, pools, channel=None):
    """Find this person's work in data already fetched this run. No network."""
    if not pools:
        return []
    channel = channel or {"kind": "discovered", "type": "internal"}
    aliases = [a.lower() for a in person.get("aliases", [])]
    out = []

    for pool_name in INTERNAL_POOL_NAMES:
        for item in (pools.get(pool_name) or []):
            if not isinstance(item, dict):
                continue
            blob = " ".join(str(item.get(k, "")) for k in
                            ("title", "description", "authors", "subtitle")).lower()
            if not any(alias in blob for alias in aliases):
                continue
            admitted, _score = is_authored_by(person, item, channel)
            if admitted:
                out.append(tag_article(person, item, channel))
    return out

# Rejected-item audit log, populated during a run and flushed by save_rejected_log().
_REJECTED = []


def _record_rejection(person, article, score):
    if len(_REJECTED) >= SUBTEXT_REJECTED_SAMPLE:
        return
    _REJECTED.append({
        "person_id": person["id"],
        "title": (article.get("title") or "")[:200],
        "link": article.get("link") or "",
        "score": score,
    })


def _normalize_url(url):
    return (url or "").strip().lower().rstrip("/").replace("http://", "https://")


def _normalize_title(title):
    return re.sub(r"[^\w\s]", " ", (title or "").lower()).strip()


def _normalize_title_key(title):
    return re.sub(r"\s+", " ", _normalize_title(title))


def _from_twitter_pool(person, channel, pools):
    """Pull this handle's tweets out of the already-built Twitter pool."""
    handle = str(channel.get("handle") or "").strip().lower()
    if not handle or not pools:
        return []
    out = []
    for item in (pools.get("twitter") or []):
        if not isinstance(item, dict):
            continue
        item_handle = str(item.get("tweet_handle") or "").strip().lower()
        if not item_handle:
            match = X_HANDLE_RE.search(item.get("link") or "")
            item_handle = match.group(1).lower() if match else ""
        if item_handle == handle:
            out.append(tag_article(person, item, channel))
    return out


def fetch_channel(person, channel, index=0, pools=None, fetcher=None):
    """Fetch one channel and return admitted, tagged articles. Never raises."""
    ctype = channel.get("type")
    if ctype == "internal":
        return scan_internal_pools(person, pools, channel)

    if ctype == "x":
        pooled = _from_twitter_pool(person, channel, pools)
        if pooled:
            return pooled  # RSSHub-quality data beats a Google re-fetch

    cfg = build_channel_feed_config(person, channel, index)
    if not cfg:
        return []

    if fetcher is None:
        from feeds import fetch_feed as fetcher  # imported lazily to keep tests light

    try:
        raw = fetcher(cfg) or []
    except Exception as err:
        print(f"  [WARN] Subtext {person['id']} ch{index} ({ctype}): {str(err)[:80]}")
        return []

    kept = []
    for article in raw:
        if not isinstance(article, dict):
            continue
        admitted, score = is_authored_by(person, article, channel)
        if admitted:
            kept.append(tag_article(person, article, channel))
        else:
            _record_rejection(person, article, score)
    return kept


def fetch_subtext(pools=None, now=None, people=None, path=None, fetcher=None):
    """Collect every person's authored work inside the freshness window."""
    now = now or datetime.now(IST_TZ)
    people = people if people is not None else load_people(path)
    if not people:
        return []

    cutoff = now - timedelta(days=SUBTEXT_FRESHNESS_DAYS)
    results = []

    for person in people:
        collected = []
        for index, channel in enumerate(person["channels"]):
            collected.extend(
                fetch_channel(person, channel, index, pools=pools, fetcher=fetcher)
            )

        fresh = []
        for article in collected:
            date_value = article.get("date")
            if date_value is None:
                fresh.append(article)
                continue
            if date_value.tzinfo is None:
                date_value = date_value.replace(tzinfo=IST_TZ)
            if date_value >= cutoff:
                fresh.append(article)

        # Owned channels first so a syndicated copy never outranks the original.
        fresh.sort(key=lambda a: 0 if a.get("channel_kind") == "owned" else 1)

        seen_urls, seen_titles, unique = set(), set(), []
        for article in fresh:
            url_key = _normalize_url(article.get("link"))
            title_key = _normalize_title_key(article.get("title"))
            if url_key and url_key in seen_urls:
                continue
            if title_key and title_key in seen_titles:
                continue
            if url_key:
                seen_urls.add(url_key)
            if title_key:
                seen_titles.add(title_key)
            unique.append(article)

        unique.sort(key=get_sort_timestamp, reverse=True)
        results.extend(unique[:SUBTEXT_MAX_PER_PERSON])

    results.sort(key=get_sort_timestamp, reverse=True)
    return results


def save_subtext_cache(cache_file, items):
    """Persist Subtext items with ISO datetime serialization."""
    payload = {
        "generated_at": datetime.now(IST_TZ).isoformat(),
        "items": [
            {**item, "date": item["date"].isoformat() if item.get("date") else None}
            for item in (items or [])
        ],
    }
    with open(cache_file, "w", encoding="utf-8") as f:
        json.dump(payload, f, indent=2)
    return payload["generated_at"]


def load_subtext_cache(cache_file):
    """Load cached Subtext items; returns (items, generated_at)."""
    try:
        with open(cache_file, "r", encoding="utf-8") as f:
            payload = json.load(f)
    except (FileNotFoundError, json.JSONDecodeError, OSError):
        return [], ""

    if isinstance(payload, list):
        raw_items, generated_at = payload, ""
    else:
        raw_items = payload.get("items", [])
        generated_at = payload.get("generated_at", "")

    items = []
    for entry in raw_items:
        if not isinstance(entry, dict):
            continue
        item = dict(entry)
        raw_date = item.get("date")
        if raw_date:
            try:
                item["date"] = datetime.fromisoformat(raw_date)
            except (ValueError, TypeError):
                item["date"] = None
        else:
            item["date"] = None
        items.append(item)
    return items, generated_at


def save_rejected_log(cache_file):
    """Flush the rejected-item audit sample for weekly filter-drift review."""
    try:
        with open(cache_file, "w", encoding="utf-8") as f:
            json.dump({
                "generated_at": datetime.now(IST_TZ).isoformat(),
                "rejected": _REJECTED,
            }, f, indent=2)
    except OSError as err:
        print(f"  [WARN] Subtext: could not write rejected log: {str(err)[:80]}")

`people.json` declares writers to follow; `subtext_fetcher.py` collects
everything they **authored** in a rolling 14-day window into the Subtext tab.
Design: `docs/superpowers/specs/2026-07-29-subtext-design.md`.

Two-tier attribution:
- **`owned`** channels (personal X account, author-scoped Blogger feed, personal
  blog) cannot contain someone else's writing, so they are trusted unfiltered.
- **`discovered`** channels (Google News `site:` queries) pass `is_authored_by()`,
  which scores authored-vs-about. The pivotal signal is inverted from intuition:
  because the item matched a query on the person's name, the name is already
  somewhere on the page — so a name in the *title* means the piece is *about*
  them, while its absence means the match was the byline.

A firm's own site is **not** `owned` — `finseclaw.com` publishes Sandeep's
partners, `gtri.co.in` publishes GTRI staff. Both are `discovered`.

Channel types: `x` (reads the already-built Twitter pool, falls back to a Google
query), `rss` (direct feed URL — personal blogs, Substacks), `blogger`
(author-label feed), `google` (site-scoped or unscoped name query), `internal`
(scans pools already fetched this run — zero network).

Tuning: weights and pattern lists live in `config.py` (`SUBTEXT_*`). Rejected
items are sampled to `static/subtext_rejected.json` for weekly drift review.

To add a person: append a block to `people.json`. No code change.
```
